# MeetRec

Приложение в строке меню macOS и CLI `meetrec` для записи звонков (Google Meet, Zoom, Telegram и любых других) с локальной транскрипцией. Системный звук (голоса собеседников) и микрофон пишутся на отдельные дорожки, затем распознаются и собираются в транскрипт с репликами «Я» и «Собеседники». По желанию Claude делает саммари: решения, задачи, открытые вопросы.

Распознавание идет локально через whisper.cpp, аудио никуда не отправляется.

## Требования

- macOS 14.5 или новее с Command Line Tools 16+ (Swift 6.0+). Проверено на macOS 26 и Swift 6.4.
- Apple Silicon рекомендуется, на Intel распознавание будет медленным.
- Около 1.5 GB на диске (модели, ffmpeg, whisper.cpp) и интернет при установке.
- Command Line Tools нужны уже для `git clone`: поставьте их заранее (`xcode-select --install`). Если Swift старше 6.0, установщик остановится до загрузок и подскажет, как обновить CLT (`softwareupdate --list`).
- Homebrew: установщик предложит поставить его сам.

## Установка

```
git clone git@github.com:ngoman/meet-rec.git && cd meet-rec && ./install.sh
```

Для приватного репо нужен доступ по SSH-ключу. Вариант по https (нужен токен или `gh auth login`): `git clone https://github.com/ngoman/meet-rec.git`.

Установщик ставит ffmpeg и whisper.cpp через Homebrew, скачивает модели (с проверкой sha256), собирает приложение в `~/Applications/MeetRec.app`, делает команду `~/.local/bin/meetrec` и запускает приложение. Повторный запуск безопасен и ничего не перекачивает. Если идет запись или обработка, установщик откажется работать (флаг `--force` собирает без перезапуска приложения).

Флаги:

- `--output-dir PATH` папка для записей встреч. Без флага при первой установке спросит (по умолчанию `~/Documents/MeetRec`).
- `--model turbo|small` модель whisper.cpp: `turbo` (large-v3-turbo-q5_0, по умолчанию, точнее) или `small` (быстрее и легче).
- `--engine whisper.cpp|openai-whisper` движок распознавания.
- `--no-restart` не перезапускать приложение.
- `--force` собрать, даже если идет запись или обработка.
- `--help` справка.

Если `~/.local/bin` не в PATH, установщик подскажет команду для `~/.zprofile`.

## Разрешения

При первой записи macOS спросит:

- Микрофон.
- Уведомления.
- Системные настройки > Конфиденциальность и безопасность > Запись экрана и системного звука > раздел «Только системный звук»: включить MeetRec. Без этого собеседников не слышно.

Приложение подписано ad-hoc, поэтому после каждой пересборки macOS может спросить разрешения заново.

## Использование

- Хоткей ⌃⌥⌘R включает и выключает запись. На старт играет Tink, на стоп Pop, приходят уведомления.
- Иконка в строке меню открывает панель: название встречи, кнопка записи, уровни дорожек, прогресс обработки, последние встречи, незавершенные сессии, папка встреч, переключатель саммари.
- Если иконки не видно, строка меню переполнена или ее перекрывает вырез экрана. Уберите лишние значки перетаскиванием с зажатым ⌘ и проверьте Системные настройки > Строка меню.

CLI:

```
meetrec start [--title T] [--no-summary]   запуск записи через приложение, печатает id сессии
meetrec stop [--wait]                      остановка, с --wait ждет обработки и печатает путь к результату
meetrec status [--json]
meetrec record [--title T] [--no-summary]  запись прямо из терминала до Ctrl+C
meetrec process <id|path> | --pending      обработать сессию (или все необработанные)
meetrec list
meetrec config                             показать конфиг
meetrec config set <ключ> <значение>
```

Коды выхода: 0 успех, 1 ошибка, 2 приложение недоступно. Предупреждения обработки выводятся в stderr и показываются в уведомлении.

Результат лежит в `<папка встреч>/<id>/`: `audio.m4a`, `transcript.md`, `transcript.json`, `summary.md`, `session.json`. Сырые дорожки хранятся в `~/Library/Application Support/MeetRec/sessions/<id>/` до успешной обработки, при ошибке они не теряются: сессию можно обработать повторно из панели или командой `meetrec process`.

## Папка встреч

По умолчанию `~/Documents/MeetRec`. Сменить можно:

- в панели: «Папка встреч» > «Изменить…»;
- командой `meetrec config set outputDir <путь>`;
- при установке флагом `--output-dir`.

Путь должен быть абсолютным или начинаться с `~`.

Приложение подхватывает новое значение без перезапуска. Если папки нет, она создается.

### iCloud

Корень iCloud Drive на диске это `~/Library/Mobile Documents/com~apple~CloudDocs/` (в Finder он называется «iCloud Drive»). Чтобы записи синхронизировались, выберите папку внутри него. Если включено «Рабочий стол и Документы в iCloud», синхронизируется и `~/Documents`, то есть папка по умолчанию тоже уедет в iCloud. Аудио занимает место: порядка 40 MB на час записи.

## Саммари через Claude

Опционально. Нужен Claude Code CLI (`claude`) с залогиненной подпиской. Текст транскрипта отправляется в Anthropic. Если `claude` не найден, саммари пропускается с предупреждением.

Отключить: переключатель в панели, `meetrec config set summary false` или `meetrec start --no-summary` для одной записи.

## Движки и модели

- `whisper.cpp` (по умолчанию): быстрый, работает через Metal. Модели лежат в `~/Library/Application Support/MeetRec/models/`. Для перехода на легкую модель: `./install.sh --model small`.
- `openai-whisper`: Python-пакет `openai-whisper`, ставится отдельно (`pip3 install openai-whisper`), модель задается ключом `whisperModel`. Включить: `meetrec config set engine openai-whisper`.

## Конфиг

`~/Library/Application Support/MeetRec/config.json`. Недостающие ключи берутся из значений по умолчанию. Значения можно менять через `meetrec config set`.

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `outputDir` | `~/Documents/MeetRec` | папка встреч |
| `language` | `ru` | язык речи, `auto` для автоопределения |
| `engine` | `whisper.cpp` | `whisper.cpp` или `openai-whisper` |
| `whisperCppBin` | `/opt/homebrew/bin/whisper-cli` | бинарь whisper.cpp |
| `whisperCppModel` | `~/Library/Application Support/MeetRec/models/ggml-large-v3-turbo-q5_0.bin` | модель whisper.cpp |
| `vadModel` | `~/Library/Application Support/MeetRec/models/ggml-silero-v5.1.2.bin` | VAD-модель, без нее распознавание идет без VAD |
| `whisperBin` | `/opt/homebrew/bin/whisper` | бинарь openai-whisper |
| `whisperModel` | `small` | модель openai-whisper |
| `ffmpegBin` | `/opt/homebrew/bin/ffmpeg` | ffmpeg |
| `claudeBin` | `~/.local/bin/claude` | Claude Code CLI |
| `summary` | `true` | делать саммари |
| `summaryModel` | `sonnet` | модель для саммари |
| `myName` | `Я` | подпись вашей дорожки |
| `othersName` | `Собеседники` | подпись системной дорожки |
| `hotkey` | `ctrl+opt+cmd+r` | применяется после перезапуска приложения; модификаторы `ctrl`, `opt`, `cmd`, `shift` и буква или цифра через `+` |

Если указанного бинаря нет, он ищется в `/opt/homebrew/bin` и `/usr/local/bin`, для `claude` еще в `~/.local/bin` и `~/.claude/local`. Найденный путь в конфиг не записывается.

## Обновление

```
git pull && ./install.sh
```

Существующий конфиг не меняется, кроме явно заданных флагов.

## Удаление

```
./uninstall.sh
```

Удаляет приложение и команду `meetrec`. Кэш сборки, модели и конфиг удаляются только после подтверждения. Записи встреч скрипт не трогает никогда.

## Ограничения

- Обработка длинных встреч занимает заметное время: распознавание идет в порядке единиц минут на час записи, затем сжатие и саммари.
- Когда на одной дорожке говорят одновременно, тихий голос может потеряться.
- Подпись ad-hoc: после пересборки разрешения могут запросить снова.
- Команда `meetrec record` из терминала пишет системный звук только если у терминала есть доступ к нему (у iTerm2 его нет), поэтому лучше `start` и `stop`.
- Без наушников микрофон ловит собеседников из динамиков. Эхо частично вычищается при обработке, но надежнее наушники.
- Предупреждайте участников встречи о записи.

## Разработка

```
scripts/build.sh   сборка и установка в ~/Applications и ~/.local/bin
scripts/test.sh    тесты (swift-testing, нужны только Command Line Tools)
```

Исходники: `Sources/MeetRecCore` (запись, обработка, конфиг), `Sources/MeetRecApp` (SwiftUI-приложение), `Sources/meetrec` (CLI), `Sources/CSupport` (Objective-C обертки). Переменная окружения `MEETREC_SUPPORT_DIR` подменяет каталог данных, нужна только для тестов.
